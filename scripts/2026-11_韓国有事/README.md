## 2. 朝鮮半島はまだ戦争中？
> 🇰🇷 1950년 한국전쟁 → 1953년 휴전협정. 평화조약이 아니라서 법적으로는 아직 '일시정지' 상태. 군사분계선~서울 약 50km, 인구 절반이 수도권.

**장면 2-1** · 화면: `old map history`
- ずんだもん：そもそも、なんで韓国と北朝鮮はそんなに仲が悪いのだ？
- 四国めたん：始まりは一九五〇年の朝鮮戦争よ。三年間、激しい戦いが続いて、一九五三年に『休戦協定』が結ばれたの。
- ずんだもん：休戦ってことは、終わったのだ？

**장면 2-2** · 화면: `border fence`
- 四国めたん：そこがポイントよ。休戦は『いったん戦うのをやめよう』という約束で、平和条約ではないの。だから法律上は、今も戦争が終わっていない状態なのよ。
- ずんだもん：七十年以上も一時停止のままなのだ！？知らなかったのだ…。

**장면 2-3** · 화면: `seoul skyline`
- 四国めたん：両国の境目には軍事境界線があって、そこから韓国の首都ソウルまでは、およそ五十キロ。
- 四国めたん：しかも韓国では、人口のおよそ半分がソウル周辺の首都圏に集まっているの。
- ずんだもん：首都が境目のすぐそばにあるのは、ちょっと怖いのだ…。

## 5. 日本が無関係でいられない理由
> 🇰🇷 유엔군 후방사령부가 도쿄 요코타 기지에 있고, 요코스카·사세보·가데나 등은 유엔군도 사용 가능. 일본 법에도 주변 사태 대응 틀이 있음.

**장면 5-1** · 화면: `airbase aerial`

- 四国めたん：実はそう単純でもないの。キーワードは『在日米軍』と『国連軍』よ。
- ずんだもん：国連軍？なんだか急に話が大きくなったのだ。

**장면 5-2** · 화면: `navy port harbor`
- 四国めたん：朝鮮戦争のとき、アメリカなどの国々は『国連軍』として戦ったの。その国連軍の後方の司令部は、今も東京の横田基地に置かれているわ。
- 四国めたん：さらに、横須賀や佐世保、沖縄の嘉手納など、日本国内のいくつかの基地は、いざというとき国連軍も使える仕組みになっているの。

**장면 5-3** · 화면: `japan parliament`

- 四国めたん：どこまで関わるかは、そのときの政府と国会の判断になる。だからこそ、私たち一人ひとりが知っておく意味があるのよ。
